# 数学语料规则

先遵循项目根目录 `SKILL.md`，再应用本文件。

## 1. 动态学习画像

最后整理：2026-07-22。以下内容由旧总 Skill 迁移而来；用户的新说明应立即覆盖，不得把本节当作永久不变的初始画像。

### 已确认基础

- 数学系大三本科阶段；
- 线性代数：向量空间、基、线性映射、矩阵与分块矩阵、内积、范数、正交投影；
- 多元微积分：多元函数、偏导数、梯度和多元链式法则；
- 实分析：Lebesgue 外测度与可测集、可测函数与简单函数逼近、Egorov 与 Lusin 定理、Lebesgue 积分、Fatou 引理、单调收敛与控制收敛、Vitali 收敛、一致可积、依测度收敛、Riesz 子列定理；
- \(L^p\) 空间、Young/Hölder/Minkowski 不等式、\(L^p\) 完备性与 Riesz–Fischer 定理；
- 点集拓扑，以及基本群、闭曲面分类和 van Kampen 定理等少量代数拓扑；
- 初步概率与数理统计：条件概率、贝叶斯公式、随机变量、期望、方差、协方差和最大似然估计。

若用户把已修课程目录、讲义目录或知识清单明确作为先修证明，目录中出现的概念按“已经学过”处理；只有用户明确说明遗忘或不熟悉时才下调。

### 当前课程与材料背景

- 应用随机过程：张波、商豪、邓军《应用随机过程（第五版）》；
- 泛函分析：许全华、马涛、尹智《泛函分析讲义》，既有资料涉及第 1—6 章与第 11 章；
- 复分析：庞学诚、梁金荣《复变函数》，既有资料涉及第 1—8 章；
- 图论：徐俊明《图论及其应用（第 4 版）》，既有资料涉及第 1—6 章。

教材与章节范围用于确定文章结构，不自动证明这些内容已经全部掌握。用户以后说明课程完成、进度推进或遗忘时，更新本节。

### 当前不应默认

- 测度论形式的条件期望；
- 生成函数和系统的随机过程基础；
- 函数空间中的随机对象；
- 乘积空间及相关可测性细节；
- 与主题有关但尚未确认的研究生层次概念。

### 当前目标

- 沿教材依赖关系建立课程知识树；
- 以定义、核心定理和证明机制为长期记忆节点；
- 理解理论为什么产生、严格结构如何解决旧问题，以及结论在更大数学体系中的位置。

## 2. 画像更新规则

当用户说明“学过、掌握、忘了、仍不懂、正在学到某章”时：

1. 在同一轮修改本节；
2. 把知识放入“已确认基础、当前不应默认、当前课程与材料背景或当前目标”中的正确位置；
3. 更新日期并删除冲突的旧判断；
4. 不因文章已经生成、已读或标为完成就自动判定掌握；
5. 正式语料只维护“未读 / 已读”等阅读状态，不设置“易 / 难”标签。

## 3. 课程型文章

教材目录只是知识树的一级导航。长期记忆节点必须是各章中的少量核心结论、判据或定理簇：

```text
教材章次
→ 核心结论或定理簇
→ 支撑结论的定义
→ 证明或构造机制
→ 典型例子、反例和跨章连接
```

课程导论应先画简洁知识树。每章优先列出 1—4 个真正值得复述的核心结论，再把历史问题、旧工具缺陷、定义、证明机制和后续用途挂到相应结论下。不要把章节名或概念名清单当作记忆骨架。

## 4. 数学小节的形式骨架

承担数学教学的实质性小节默认按以下顺序：

1. 严格定义与约定：对象类型、定义域、陪域、量词和符号；
2. 一至三条核心定理、命题或判据，完整写出假设与结论；
3. 解释公式中的对象、整体含义和结论比定义新增了什么；
4. 说明历史动机、旧理论缺陷和选择该定义的原因；
5. 给出完整证明、证明骨架或构造思路，并明确三者区别；
6. 用例子检验定义，用反例暴露假设边界，并连接前后结论。

形式骨架先出现，解释随后跟上。不要用长篇动机推迟读者第一次看到正式对象和结论。

## 5. 公式与证明

关键公式按以下顺序处理：

1. 若属于定义或定理，先放入完整的正式陈述；
2. 解释公式整体在说什么；
3. 逐项说明对象类型、范围和意义；
4. 说明为什么会预期这种关系；
5. 逐步推导并标注所用定义、假设或已有定理；
6. 解释结果，并指出假设变化时哪一步失效。

不要用“显然”“容易得到”跳过承担核心论证作用的步骤。即使概念属于已学内容，首次作为本文关键对象出现时也要声明采用的定义和符号。

## 6. 难度、信息密度与自检

- 不因文章位置靠后或符号累积而突然升难；
- 降低跨段符号依赖和回翻需求，不降低新信息量、定理严格性或数学深度；
- 每个教材分支重新声明关键符号并局部闭环；
- 区分“本篇需要掌握”和“本篇只需识别”；
- 已学内容压缩复述，把篇幅让给新的结构联系、定理、证明机制和应用；
- 每完成 2—3 个核心小节，插入 1—3 道局部自检，答案紧随其后或折叠显示；
- 文末综合题只连接全文，不首次引入新符号、定理或更高难度推导。

## 7. 数学史

数学史按真实问题发展组织：

```text
旧理论能处理什么
→ 哪个问题迫使它失效
→ 新对象和严格定义怎样出现
→ 新理论解决了什么
→ 后续修正、分支和未解问题
```

解释“早期问题为何成为现代学科起点”时，必须区分：

- 当时实际使用的方法；
- 后来建立的现代形式化；
- 不能倒灌给早期作者的后世概念。

先建立问题与理论谱系，再写人物贡献，不把数学史写成人名和年份清单。

## 8. 已吸收的个性化反馈

- 数学课程全景不能停留在目录和概念地图，必须以核心结论与定理簇为记忆节点；
- 数学小节必须先给教科书式严格定义和核心定理，再解释直觉、历史和证明机制；
- 不能把“降低累积难度”执行成降低信息密度；
- 自检要分散在对应知识段落后；
- 公式必须先进入完整正式陈述，再解释含义并逐步推导；
- 课程历史背景必须挂到它所解释的章节和结论下；
- 阅读状态与难度评价必须分开。

新的数学领域反馈若能跨文章复用，更新本节对应规则；只适用于一本教材或一个系列的要求留在原文章反馈区。
