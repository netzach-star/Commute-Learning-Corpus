0. 先明确本文要回答什么

“做出 GPT”至少有三种不同含义。

目标 最终产物 必须包含的部分
架构级实现 一个能在小语料上训练和生成文本的微型 GPT Tokenizer、Embedding、Transformer、损失、训练循环、采样
模型级实现 一个经过真实预训练、具有一定语言能力的 Base Model 架构级内容，加上数据管线、稳定训练、评测与规模化计算
产品级实现 一个能理解指令、对话并作为服务运行的助手模型 Base Model，加上后训练、安全评测、推理服务和接口

个人完全可以完整实现第一种，并在有限算力下完成小规模的第二、第三种。但不能据此声称“复刻 GPT-4”：其公开报告没有提供足以精确重建全部架构、数据和训练过程的细节。

本文真正回答的是：

从字符串和数学公式出发，经过哪些对象、函数和系统，才能得到一个可训练、可生成、可对话并可被 Agent 调用的 GPT-like 系统？

阅读时请区分三类陈述：

  1. 数学定义：例如交叉熵是什么；
  2. 数学推导：例如最大似然为何导出交叉熵；
  3. 建模或工程选择：例如层数、头数、位置编码方案。

第三类通常不是由某个定理唯一推出的。Transformer 是为解决一组表示与计算问题设计并由实验检验的模型族，不是从公理中证明出的唯一答案。

2. GPT 的严格数学对象

2.1 从字符串到 Token 序列

定义有限词表

𝒱={v1,v2,…,vV}, \mathcal V=\{v_1,v_2,\ldots,v_V\},

其中 V=|𝒱|V=|\mathcal V|。Token 可以是字节、字符、词或子词片段。

Tokenizer 可以抽象为映射

τ:𝒮→𝒱*, \tau:\mathcal S\longrightarrow\mathcal V^*,

其中 𝒮\mathcal S 是字符串集合，𝒱*\mathcal V^* 是由 𝒱\mathcal V 中元素组成的所有有限序列。

例如，一段字符串经 Tokenizer 后得到

x=(x1,…,xT),xt∈𝒱. x=(x_1,\ldots,x_T),\qquad x_t\in\mathcal V.

Tokenizer 解决的不是“理解语义”，而是确定神经网络所面对的离散基本单位。

2.2 模型输出所在的空间

先定义词表上的概率单纯形：

ΔV−1={p∈ℝV:pi≥0,∑i=1Vpi=1}. \Delta^{V-1} = \left\{ p\in\mathbb R^V: p_i\ge 0,\ \sum_{i=1}^{V}p_i=1 \right\}.

其中每个 p∈ΔV−1p\in\Delta^{V-1} 都对应词表 𝒱\mathcal V 上的一个概率分布。

定义：自回归语言模型

对每个允许的序列长度 tt，语言模型给出一个参数化映射

fθ(t):𝒱t→ΔV−1. f_\theta^{(t)}:\mathcal V^t\longrightarrow\Delta^{V-1}.

输入是已有 Token 序列 (x1,…,xt)(x_1,\ldots,x_t)，输出是下一个 Token 在整个词表上的条件概率分布。θ\theta 表示模型全部可训练参数。

这个定义没有规定内部一定使用 Transformer。GPT 的特殊性在于：它使用 Decoder-only Transformer 参数化这些映射，并从左到右进行生成式预训练。

2.3 为什么“预测下一个 Token”足以定义全文概率

现在解释公式的目的：我们希望把“整段文本出现的概率”化成模型能够反复计算的“下一个 Token 概率”。

由条件概率链式法则，

pθ(x1,…,xT)=pθ(x1)pθ(x2∣x1)⋯pθ(xT∣x1,…,xT−1)=∏t=1Tpθ(xt∣x<t), \begin{aligned} p_\theta(x_1,\ldots,x_T) &=p_\theta(x_1)\, p_\theta(x_2\mid x_1)\cdots p_\theta(x_T\mid x_1,\ldots,x_{T-1})\\ &=\prod_{t=1}^{T}p_\theta(x_t\mid x_{<t}), \end{aligned}

其中 x<t=(x1,…,xt−1)x_{<t}=(x_1,\ldots,x_{t-1})。

因此，只要模型能对每个前缀给出下一 Token 的条件分布，就已经定义了整个 Token 序列的联合分布。“预测下一个 Token”不是随意选择的练习题，而是一种完整的联合概率建模方式。

3. 张量：模型实际操作的对象

3.1 数学中的严格定义

设 V1,…,VkV_1,\ldots,V_k 是有限维实向量空间。张量积

V1⊗⋯⊗Vk V_1\otimes\cdots\otimes V_k

是一个向量空间，并带有多线性映射

ι:V1×⋯×Vk→V1⊗⋯⊗Vk, \iota:V_1\times\cdots\times V_k \longrightarrow V_1\otimes\cdots\otimes V_k,

满足泛性质：对任意向量空间 WW 和多线性映射

f:V1×⋯×Vk→W, f:V_1\times\cdots\times V_k\to W,

存在唯一线性映射

f̃:V1⊗⋯⊗Vk→W \widetilde f:V_1\otimes\cdots\otimes V_k\to W

使得 f=f̃∘ιf=\widetilde f\circ\iota。

这一定义的核心含义是：张量积把“对多个变量分别线性”的问题，转化为“对一个张量变量线性”的问题。

选定各空间的基后，张量可以用带有多个下标的坐标数组表示：

Ai1i2⋯ik. A_{i_1i_2\cdots i_k}.

3.2 深度学习中的宽松用法

深度学习框架通常把“张量”宽松地用于指代带有多条轴的数值数组。例如

H∈ℝB×T×d. H\in\mathbb R^{B\times T\times d}.

一旦选择标准基，它可以视为

ℝB⊗ℝT⊗ℝd \mathbb R^B\otimes\mathbb R^T\otimes\mathbb R^d

中某个张量的坐标表示。工程中主要关心：

  • 每条轴表示什么；
  • 每条轴的长度；
  • 运算在哪些轴上进行；
  • 是否需要保存梯度。

所以在 LLM 语境中，可以先把 Tensor 理解为：

带有明确轴语义、能够参与自动微分的多维数组。

3.3 阶数、形状与矩阵秩

对

H∈ℝB×T×d, H\in\mathbb R^{B\times T\times d},

它有三条轴，形状为

shape(H)=(B,T,d). \operatorname{shape}(H)=(B,T,d).

这与矩阵秩不同：

  • Tensor 的阶数或 ndim 是下标个数；
  • Shape 是每个下标的取值范围；
  • 矩阵秩是像空间维数；
  • 一般张量秩是另一个更复杂的分解概念。

在 GPT 中：

  • BB：一次并行处理的序列数；
  • TT：每个序列的 Token 位置数；
  • dd：每个 Token 的隐藏特征数。

元素 HbtiH_{bti} 表示第 bb 个序列、第 tt 个 Token、第 ii 个隐藏特征。

若对每个 Token 应用同一线性映射 W∈ℝd×d′W\in\mathbb R^{d\times d'}，则

Ybtj=∑i=1dHbtiWij. Y_{btj}=\sum_{i=1}^{d}H_{bti}W_{ij}.

求和只发生在特征轴 ii 上，Batch 轴 bb 和位置轴 tt 被保留，所以

Y∈ℝB×T×d′. Y\in\mathbb R^{B\times T\times d'}.

这就是“一个线性层同时作用于所有 Batch、所有 Token”的准确含义。

4. 从 Token 到可训练向量

4.1 One-hot 坐标

为词表第 ii 个 Token 定义标准基向量

ei=(0,…,0,1,0,…,0)⊤∈ℝV. e_i=(0,\ldots,0,1,0,\ldots,0)^\top\in\mathbb R^V.

它精确表示 Token 身份，但任意两个不同 Token 都彼此正交，不能表达可学习的连续关系，而且维度等于词表大小。

4.2 Embedding

定义可训练矩阵

E∈ℝV×d. E\in\mathbb R^{V\times d}.

第 ii 个 Token 的向量表示为

hi=ei⊤E=Ei,:∈ℝd. h_i=e_i^\top E=E_{i,:}\in\mathbb R^d.

所谓 Embedding Lookup，本质上就是取矩阵 EE 的第 ii 行。

对序列 (x1,…,xT)(x_1,\ldots,x_T)，

H(0)=[Ex1,:Ex2,:⋮ExT,:]∈ℝT×d. H^{(0)} = \begin{bmatrix} E_{x_1,:}\\ E_{x_2,:}\\ \vdots\\ E_{x_T,:} \end{bmatrix} \in\mathbb R^{T\times d}.

Embedding 的功能不是保存每个词的字典释义，而是把离散符号放入连续向量空间，使线性变换、相似关系和梯度优化成为可能。

5. 神经网络：带参数的复合函数

5.1 仿射层

采用行向量约定。给定 x∈ℝnx\in\mathbb R^n，仿射层为

f(x)=xW+b, f(x)=xW+b,

其中 W∈ℝn×mW\in\mathbb R^{n\times m}、b∈ℝmb\in\mathbb R^m，输出属于 ℝm\mathbb R^m。W,bW,b 不是程序员手工填入的规则，而是训练得到的参数。

5.2 为什么必须加入非线性

两个仿射变换复合：

f1(x)=xW1+b1,f2(y)=yW2+b2. f_1(x)=xW_1+b_1,\qquad f_2(y)=yW_2+b_2.

则

f2(f1(x))=(xW1+b1)W2+b2=x(W1W2)+(b1W2+b2), \begin{aligned} f_2(f_1(x)) &=(xW_1+b_1)W_2+b_2\\ &=x(W_1W_2)+(b_1W_2+b_2), \end{aligned}

仍然是一个仿射变换。无论堆叠多少纯线性层，都不会突破单个仿射映射的表达范围。

因此在中间加入逐坐标非线性函数 ϕ\phi：

MLP(x)=ϕ(xW1+b1)W2+b2. \operatorname{MLP}(x) = \phi(xW_1+b_1)W_2+b_2.

在 Transformer 中，Attention 负责不同 Token 之间交换信息；MLP 则对每个 Token 已聚合的信息进行非线性变换。

6. Softmax 与交叉熵

6.1 Softmax 把分数变成概率

模型最后产生

z=(z1,…,zV)∈ℝV, z=(z_1,\ldots,z_V)\in\mathbb R^V,

称为 logits。它们可以是任意实数，不能直接作为概率。

Softmax 定义为

σ:ℝV→ΔV−1,σ(z)i=ezi∑j=1Vezj. \sigma:\mathbb R^V\to\Delta^{V-1}, \qquad \sigma(z)_i = \frac{e^{z_i}}{\sum_{j=1}^{V}e^{z_j}}.

记 qi=σ(z)iq_i=\sigma(z)_i。由于 qi>0q_i>0 且 ∑iqi=1\sum_iq_i=1，qq 是词表上的概率分布。

对任意常数 cc，

σ(z+c𝟏)i=ezi+c∑jezj+c=σ(z)i. \sigma(z+c\mathbf1)_i = \frac{e^{z_i+c}}{\sum_je^{z_j+c}} = \sigma(z)_i.

所以 logits 的相对差值而非绝对值决定概率。实际计算时常减去最大 logit，避免指数上溢。

6.2 熵、KL 散度与交叉熵

设 p,q∈ΔV−1p,q\in\Delta^{V-1}。

定义：熵

H(p)=−∑i=1Vpilogpi, H(p)=-\sum_{i=1}^{V}p_i\log p_i,

约定 0log0=00\log0=0。它刻画从 pp 采样时的不确定程度。

定义：KL 散度

当 pi>0p_i>0 蕴含 qi>0q_i>0 时，

DKL(p‖q)=∑i=1Vpilogpiqi. D_{\mathrm{KL}}(p\Vert q) = \sum_{i=1}^{V}p_i\log\frac{p_i}{q_i}.

它通常不对称，所以不是距离。

定义：交叉熵

H(p,q)=−∑i=1Vpilogqi. H(p,q) = -\sum_{i=1}^{V}p_i\log q_i.

它表示事件真实服从 pp，但使用预测分布 qq 为事件赋予概率时的平均负对数概率。

6.3 交叉熵与 KL 散度的关系

这次推导要回答：为什么最小化交叉熵会迫使预测分布接近真实分布？

由定义，

DKL(p‖q)=∑ipilogpiqi=∑ipilogpi−∑ipilogqi=−H(p)+H(p,q). \begin{aligned} D_{\mathrm{KL}}(p\Vert q) &=\sum_i p_i\log\frac{p_i}{q_i}\\ &=\sum_i p_i\log p_i-\sum_i p_i\log q_i\\ &=-H(p)+H(p,q). \end{aligned}

所以

H(p,q)=H(p)+DKL(p‖q). \boxed{H(p,q)=H(p)+D_{\mathrm{KL}}(p\Vert q)}.

真实分布 pp 固定时，H(p)H(p) 与模型参数无关。因此最小化 H(p,q)H(p,q) 等价于最小化 DKL(p‖q)D_{\mathrm{KL}}(p\Vert q)。

6.4 单一正确 Token 的损失

若正确 Token 是第 yy 个，真实分布为标准基向量 eye_y：

pi=𝟏{i=y}. p_i=\mathbf1_{\{i=y\}}.

代入交叉熵：

H(ey,q)=−∑ipilogqi=−logqy. H(e_y,q) =-\sum_i p_i\log q_i =-\log q_y.

所以正确 Token 概率越低，损失越大；若 qy→0q_y\to0，损失趋向正无穷。

6.5 为什么最大似然等价于交叉熵训练

设训练样本为 (c(n),y(n))(c^{(n)},y^{(n)})，其中 c(n)c^{(n)} 是上下文，y(n)y^{(n)} 是真实下一 Token。似然为

L(θ)=∏n=1Nqθ(y(n)∣c(n)). L(\theta) = \prod_{n=1}^{N} q_\theta(y^{(n)}\mid c^{(n)}).

最大化似然等价于最大化对数似然，也等价于最小化

ℒ(θ)=−1N∑n=1Nlogqθ(y(n)∣c(n)). \mathcal L(\theta) = -\frac1N\sum_{n=1}^{N} \log q_\theta(y^{(n)}\mid c^{(n)}).

每一项正是 one-hot 真实分布与模型分布之间的交叉熵。因此

最大似然估计⇔最小化经验交叉熵. \boxed{\text{最大似然估计}\Longleftrightarrow\text{最小化经验交叉熵}}.

6.6 交叉熵对 logits 的梯度

这次推导要说明：损失怎样直接告诉模型应提高哪个 Token 的分数、降低哪些 Token 的分数。

因为

qy=ezy∑iezi, q_y=\frac{e^{z_y}}{\sum_i e^{z_i}},

所以

ℒ=−logqy=−zy+log∑iezi. \mathcal L=-\log q_y =-z_y+\log\sum_i e^{z_i}.

对 zjz_j 求偏导：

∂ℒ∂zj=−∂zy∂zj+ezj∑iezi=−𝟏{j=y}+qj. \begin{aligned} \frac{\partial\mathcal L}{\partial z_j} &=-\frac{\partial z_y}{\partial z_j} +\frac{e^{z_j}}{\sum_i e^{z_i}}\\ &=-\mathbf1_{\{j=y\}}+q_j. \end{aligned}

即

∂ℒ∂zj=qj−𝟏{j=y}. \boxed{ \frac{\partial\mathcal L}{\partial z_j} =q_j-\mathbf1_{\{j=y\}} }.

对正确 Token，梯度为 qy−1<0q_y-1<0，梯度下降会提高它的 logit；对错误 Token，梯度为 qj>0q_j>0，梯度下降会降低它的 logit。

7. Attention：让一个 Token 读取其他 Token

7.1 它解决的缺陷

若只对每个位置独立应用

ht′=MLP(ht), h_t'=\operatorname{MLP}(h_t),

那么 ht′h_t' 完全不知道其他位置。语言中的指代、修饰、长距离依赖都要求某个位置读取上下文。Self-Attention 提供的正是序列内部的信息混合。

7.2 Query、Key、Value

暂时忽略 Batch。令

H∈ℝT×d, H\in\mathbb R^{T\times d},

第 tt 行 hth_t 是第 tt 个 Token 的表示。定义可训练矩阵

WQ,WK∈ℝd×dk,WV∈ℝd×dv. W_Q,W_K\in\mathbb R^{d\times d_k}, \qquad W_V\in\mathbb R^{d\times d_v}.

计算

Q=HWQ,K=HWK,V=HWV. Q=HW_Q,\qquad K=HW_K,\qquad V=HW_V.

第 tt 行分别为 qt,kt,vtq_t,k_t,v_t：

  • qtq_t：位置 tt 用哪些特征寻找信息；
  • ksk_s：位置 ss 用哪些特征接受匹配；
  • vsv_s：若位置 ss 被读取，实际传递什么信息。

这些不是预先赋予语言意义的符号，而是训练出来的三组线性投影。

7.3 匹配分数及缩放

位置 tt 对位置 ss 的分数为

rts=qtks⊤dk. r_{ts}=\frac{q_tk_s^\top}{\sqrt{d_k}}.

若把各坐标粗略视为独立、均值为 00、方差为 11，则点积

∑i=1dkqtiksi \sum_{i=1}^{d_k}q_{ti}k_{si}

的方差约为 dkd_k，标准差约为 dk\sqrt{d_k}。除以 dk\sqrt{d_k} 后，分数量级不随维度快速膨胀，从而减少 Softmax 过早饱和。这是方差控制的设计理由，不是唯一性定理。

7.4 因果 Mask

GPT 在位置 tt 不能读取未来位置。定义

Mts={0,s≤t,−∞,s>t. M_{ts}= \begin{cases} 0,&s\le t,\\ -\infty,&s>t. \end{cases}

逐行 Softmax 后，

αts=exp(rts+Mts)∑j=1Texp(rtj+Mtj). \alpha_{ts} = \frac{\exp(r_{ts}+M_{ts})} {\sum_{j=1}^{T}\exp(r_{tj}+M_{tj})}.

当 s>ts>t 时，αts=0\alpha_{ts}=0。输出为

ot=∑s=1Tαtsvs=∑s≤tαtsvs. o_t=\sum_{s=1}^{T}\alpha_{ts}v_s =\sum_{s\le t}\alpha_{ts}v_s.

因为 αts≥0\alpha_{ts}\ge0 且 ∑sαts=1\sum_s\alpha_{ts}=1，oto_t 是历史 Value 向量的凸组合。

矩阵形式为

Attention(Q,K,V)=softmax(QK⊤dk+M)V. \boxed{ \operatorname{Attention}(Q,K,V) = \operatorname{softmax} \left( \frac{QK^\top}{\sqrt{d_k}}+M \right)V }.

7.5 多头注意力

多头注意力使用多组 WQ(r),WK(r),WV(r)W_Q^{(r)},W_K^{(r)},W_V^{(r)}，分别计算

O(r)=Attention(HWQ(r),HWK(r),HWV(r)). O^{(r)} = \operatorname{Attention} \left( HW_Q^{(r)},HW_K^{(r)},HW_V^{(r)} \right).

随后拼接并投影：

MHA(H)=Concat(O(1),…,O(h))WO. \operatorname{MHA}(H) = \operatorname{Concat} \left( O^{(1)},\ldots,O^{(h)} \right)W_O.

多头允许模型在不同投影空间并行建立关系，但不能先验断言某个头一定表示语法、指代或事实关系。

8. 位置、归一化与残差

8.1 为什么需要位置表示

普通 Self-Attention 本身主要根据内容进行集合式匹配，没有天然的绝对位置坐标。GPT 必须区分“甲批评乙”和“乙批评甲”，也要表达距离。

一种方案是学习位置向量 Pt∈ℝdP_t\in\mathbb R^d：

Ht(0)=E[xt]+Pt. H_t^{(0)}=E[x_t]+P_t.

另一类方案把位置信息作用于 Query 与 Key。具体方案可以更换，但“向模型提供顺序和距离信息”这一功能不可省略。

8.2 Layer Normalization

对隐藏向量 h=(h1,…,hd)h=(h_1,\ldots,h_d)，先定义

μ(h)=1d∑i=1dhi, \mu(h)=\frac1d\sum_{i=1}^{d}h_i,

σ2(h)=1d∑i=1d(hi−μ(h))2. \sigma^2(h) = \frac1d\sum_{i=1}^{d}(h_i-\mu(h))^2.

LayerNorm 为

LN(h)i=γihi−μ(h)σ2(h)+ε+βi. \operatorname{LN}(h)_i = \gamma_i \frac{h_i-\mu(h)} {\sqrt{\sigma^2(h)+\varepsilon}} +\beta_i.

它对同一个 Token 的隐藏特征归一化，不跨 Batch 统计。标准化控制激活尺度，γi,βi\gamma_i,\beta_i 又允许模型学习所需的缩放和平移。

8.3 残差连接

残差结构为

y=x+F(x). y=x+F(x).

其 Jacobian 为

∂y∂x=I+∂F∂x. \frac{\partial y}{\partial x} = I+\frac{\partial F}{\partial x}.

恒等项 II 为信息和梯度提供了较短通路。它不保证深层训练永远稳定，但显著降低了“每层都必须完整重建输入表示”的负担。

9. Transformer Block 与完整 GPT

9.1 一个 Pre-Norm Decoder Block

设第 ℓ\ell 层输入为 H(ℓ)H^{(\ell)}。注意力子层：

U(ℓ)=H(ℓ)+MHA(Norm(H(ℓ))). U^{(\ell)} = H^{(\ell)} + \operatorname{MHA} \left( \operatorname{Norm}(H^{(\ell)}) \right).

MLP 子层：

H(ℓ+1)=U(ℓ)+MLP(Norm(U(ℓ))). H^{(\ell+1)} = U^{(\ell)} + \operatorname{MLP} \left( \operatorname{Norm}(U^{(\ell)}) \right).

于是每层的功能分工是：

  • Attention：不同 Token 之间传递信息；
  • MLP：每个 Token 内部进行非线性特征变换；
  • Residual：保留原表示并提供直接通路；
  • Normalization：控制数值尺度。

9.2 完整前向传播

输入 Token ID 为

X∈{1,…,V}B×T. X\in\{1,\ldots,V\}^{B\times T}.

经过 Token 和位置表示得到

H(0)∈ℝB×T×d. H^{(0)}\in\mathbb R^{B\times T\times d}.

堆叠 LL 层：

H(ℓ+1)=Blockℓ(H(ℓ)),ℓ=0,…,L−1. H^{(\ell+1)} = \operatorname{Block}_\ell(H^{(\ell)}), \qquad \ell=0,\ldots,L-1.

最终归一化并投影回词表空间：

H̃=Norm(H(L)), \widetilde H=\operatorname{Norm}(H^{(L)}),

Z=H̃WU∈ℝB×T×V,WU∈ℝd×V. Z=\widetilde H W_U \in\mathbb R^{B\times T\times V}, \qquad W_U\in\mathbb R^{d\times V}.

Zbt:Z_{bt:} 是第 bb 个序列、第 tt 个位置的词表 logits。Softmax 给出

pθ(xt+1=vi∣x≤t)=exp(Zbti)∑j=1Vexp(Zbtj). p_\theta(x_{t+1}=v_i\mid x_{\le t}) = \frac{\exp(Z_{bti})} {\sum_{j=1}^{V}\exp(Z_{btj})}.

至此，前文定义的条件概率模型才真正被一个可计算函数实现。

9.3 因果性为何能贯穿多层

第一层位置 tt 只能读取位置 1,…,t1,\ldots,t，所以 Ht(1)H_t^{(1)} 只依赖 x≤tx_{\le t}。

假设第 ℓ\ell 层的 Hs(ℓ)H_s^{(\ell)} 只依赖 x≤sx_{\le s}。第 ℓ+1\ell+1 层位置 tt 只能读取

H1(ℓ),…,Ht(ℓ), H_1^{(\ell)},\ldots,H_t^{(\ell)},

这些量最多依赖 x≤tx_{\le t}，所以 Ht(ℓ+1)H_t^{(\ell+1)} 仍只依赖 x≤tx_{\le t}。由归纳法，最终 logits 合法定义 pθ(xt+1∣x≤t)p_\theta(x_{t+1}\mid x_{\le t})。

9.4 参数量主要来自哪里

假设隐藏维度为 dd，MLP 中间维度为 4d4d，并忽略 Bias 和 Norm 小项。

Attention 中 WQ,WK,WV,WOW_Q,W_K,W_V,W_O 各约有 d2d^2 个参数，合计 4d24d^2。

MLP 的两个矩阵大小为 d×4dd\times4d 和 4d×d4d\times d，合计 8d28d^2。

每个 Block 约有 12d212d^2 个参数，LL 层约有 12Ld212Ld^2。若输入 Embedding 与输出权重共享，粗略总量为

N≈12Ld2+Vd. \boxed{N\approx12Ld^2+Vd}.

它说明主体参数量随隐藏维度近似按平方增长，但并不证明参数更多必然表现更好。

10. 训练：从随机参数到 Base GPT

10.1 标签从哪里来

给定序列 (x1,x2,…,xT)(x_1,x_2,\ldots,x_T)，输入和标签错开一位：

输入：x₁  x₂  x₃  …  x₍T₋₁₎
标签：x₂  x₃  x₄  …  xₜ

单序列经验损失为

ℒ̂(θ)=−1T−1∑t=1T−1logpθ(xt+1∣x≤t). \widehat{\mathcal L}(\theta) = -\frac1{T-1} \sum_{t=1}^{T-1} \log p_\theta(x_{t+1}\mid x_{\le t}).

训练时真实历史 Token 已全部存在，因果 Mask 又阻止未来泄漏，所以所有位置可以在一次前向传播中并行计算。推理时未来 Token 尚不存在，才必须逐个生成。

10.2 为什么负梯度局部降低损失

把全部参数展开为 θ∈ℝN\theta\in\mathbb R^N。对小扰动 δ\delta，

ℒ(θ+δ)=ℒ(θ)+⟨∇ℒ(θ),δ⟩+o(∥δ∥). \mathcal L(\theta+\delta) = \mathcal L(\theta) + \langle\nabla\mathcal L(\theta),\delta\rangle + o(\|\delta\|).

选择 δ=−η∇ℒ(θ)\delta=-\eta\nabla\mathcal L(\theta)，其中 η>0\eta>0，得到

ℒ(θ+δ)=ℒ(θ)−η∥∇ℒ(θ)∥2+o(η∥∇ℒ∥). \mathcal L(\theta+\delta) = \mathcal L(\theta) - \eta\|\nabla\mathcal L(\theta)\|^2 + o(\eta\|\nabla\mathcal L\|).

当步长足够小时，一阶项为负。这给出梯度下降

θk+1=θk−η∇ℒ(θk) \theta_{k+1} = \theta_k-\eta\nabla\mathcal L(\theta_k)

的局部理由。

10.3 反向传播与自动微分

GPT 是大量函数的复合：

θ→Q,K,V→Attention→H→Z→ℒ. \theta \longrightarrow Q,K,V \longrightarrow \operatorname{Attention} \longrightarrow H \longrightarrow Z \longrightarrow\mathcal L.

反向传播不是新的微积分法则，而是按计算图的反向顺序复用中间结果、应用多元链式法则。实际系统通常不显式构造巨大 Jacobian，而是计算向量—Jacobian 乘积并累积到每个参数。

自动微分也不是有限差分。有限差分需要反复扰动每个坐标，成本极高且有截断误差；自动微分把程序分解为已知导数规则的基本运算，在浮点误差范围内计算解析链式法则。

10.4 Mini-batch

完整数据损失为

ℒ(θ)=1N∑n=1Nℓn(θ). \mathcal L(\theta) = \frac1N\sum_{n=1}^{N}\ell_n(\theta).

每次遍历全部数据再更新一次不可行，于是抽取子集 ℬ\mathcal B，使用

gℬ=1|ℬ|∑n∈ℬ∇ℓn(θ) g_{\mathcal B} = \frac1{|\mathcal B|} \sum_{n\in\mathcal B}\nabla\ell_n(\theta)

近似完整梯度。适当随机采样下，它是完整梯度的无偏估计。

10.5 Adam 的功能

普通梯度下降对所有坐标使用同一学习率。Adam 为每个参数坐标维护梯度的一阶和二阶移动平均：

mt=β1mt−1+(1−β1)gt, m_t=\beta_1m_{t-1}+(1-\beta_1)g_t,

vt=β2vt−1+(1−β2)gt⊙gt. v_t=\beta_2v_{t-1}+(1-\beta_2)g_t\odot g_t.

偏差修正后

m̂t=mt1−β1t,v̂t=vt1−β2t, \widehat m_t=\frac{m_t}{1-\beta_1^t}, \qquad \widehat v_t=\frac{v_t}{1-\beta_2^t},

更新为

θt+1=θt−ηm̂tv̂t+ε. \theta_{t+1} = \theta_t - \eta\frac{\widehat m_t} {\sqrt{\widehat v_t}+\varepsilon}.

mtm_t 平滑方向，vtv_t 估计各坐标近期梯度平方尺度。Adam 是训练算法，不是 GPT 概率模型定义的一部分。

11. 数据系统：模型到底从什么中学习

完整预训练数据系统不是“找一堆网页”，而是多个功能模块：

模块 功能
数据获取 决定覆盖哪些语言、领域、年代和文本形式
文档解析 从网页、代码、书籍等载体提取实际内容
规范化 统一编码、空白、异常字符和格式
去重 减少同一内容被反复训练及记忆风险
质量过滤 降低垃圾文本、模板页面、乱码和低质量内容
安全与合规处理 处理个人信息、有害内容和许可证边界
数据混合 决定语言、代码、数学、对话等数据比例
数据集划分 分离训练与验证数据，减少评测污染
Tokenization 把文档变成 Token ID
Packing 将不同长度文档组合成适合计算的序列
采样与批处理 按混合比例持续产生训练 Batch

这些模块分别解决不同问题，不能由某个单一“数据工具”代替。

Tokenizer 还直接连接词表大小、序列长度和计算成本。增大词表可能缩短序列，却增大 Embedding 和输出矩阵；减小词表可能缩小这些矩阵，却让同一文本占据更多 Token。

12. 规模化训练：计算、显存与通信

训练显存中不只有模型参数，还包括参数梯度、优化器状态、当前 Batch 的中间激活、Attention 中间量以及通信和临时计算缓冲区。

大规模训练的三个核心瓶颈是

计算量、显存容量、设备间通信. \boxed{\text{计算量、显存容量、设备间通信}}.

规模化方法可以按“切分什么”理解：

方法 切分对象 解决的问题 代价
数据并行 Batch 提高总体吞吐 同步梯度
状态分片 参数、梯度、优化器状态 降低单卡存储 使用时聚合
张量并行 单层大矩阵 一层无法放入单卡 层内频繁通信
流水线并行 不同网络层 整体模型无法放入单卡 激活传输与流水线空闲
序列并行 Token 位置 长上下文激活过大 交换序列状态

重要的不是记住所有框架名称，而是理解系统究竟切 Batch、切状态、切矩阵、切层还是切序列。

Attention 会产生 T×TT\times T 级别的交互。某些高效算法不改变 Attention 的数学函数，而是通过分块减少中间量在慢速显存与快速片上存储间的往返。这说明“算什么”和“数据在硬件哪里”是两个不同层次的问题。

模型规模 NN、训练 Token 数 DD 与计算预算 CC 也必须联合设计。对稠密模型常粗略写作

C∝ND. C\propto ND.

模型很大但数据不足会训练不充分；数据极多而模型太小又会受容量限制。所谓 Scaling Laws 是对这些关系的经验研究，不是“参数越多必然越好”的口号。

13. 从 Base GPT 到助手模型

预训练只要求预测真实语料中的下一个 Token。语料既包含正确回答，也包含争论、错误、叙事和无关续写，所以 Base Model 不天然服从用户，也没有被目标函数直接要求诚实、安全或简洁。

13.1 监督指令微调

指令数据通常是 (用户请求,理想助手回答)(\text{用户请求},\text{理想助手回答})。它仍使用交叉熵，但常只对助手回答位置集合 𝒜\mathcal A 计算：

ℒSFT=−∑t∈𝒜logpθ(xt∣x<t). \mathcal L_{\mathrm{SFT}} = -\sum_{t\in\mathcal A} \log p_\theta(x_t\mid x_{<t}).

它把 Base Model 的广泛文本能力重新组织为接收指令、识别角色、直接回答和遵循格式的行为。

13.2 偏好对齐

同一提示 xx 可能有两个语言上都成立的回答 y+y^+ 与 y−y^-，但人类更偏好前者。偏好数据记录

(x,y+,y−). (x,y^+,y^-).

后续算法可以先学习奖励函数再优化模型，也可以直接增大优选回答相对于劣选回答的对数概率差。它解决的是“许多可能输出中哪一种更符合帮助性、安全性和产品规范”，而不是重新定义 Transformer。

14. 推理：模型权重如何生成文本

14.1 自回归循环

给定上下文 x≤Tx_{\le T}，模型得到 pθ(xT+1∣x≤T)p_\theta(x_{T+1}\mid x_{\le T})，选出或采样 xT+1x_{T+1}，再计算 pθ(xT+2∣x≤T+1)p_\theta(x_{T+2}\mid x_{\le T+1})，不断重复，直到生成结束 Token、达到长度上限或命中外部停止条件。

14.2 Temperature

带温度 τ>0\tau>0 的分布为

qi(τ)=exp(zi/τ)∑jexp(zj/τ). q_i(\tau) = \frac{\exp(z_i/\tau)} {\sum_j\exp(z_j/\tau)}.

当 τ→0+\tau\to0^+ 时，分布集中于最大 logit；当 τ→∞\tau\to\infty 时，分布趋向均匀。Temperature 只改变从已有条件分布中选择 Token 的随机程度，不增加模型知识。

14.3 KV Cache

历史位置 ss 的 Key 与 Value 一旦计算完成，未来 Token 不会改变它们。因此可以缓存

K1:T,V1:T, K_{1:T},V_{1:T},

生成新 Token 时只计算新位置的 qT+1,kT+1,vT+1q_{T+1},k_{T+1},v_{T+1}，再让新 Query 读取历史缓存。

KV Cache 避免反复计算全部历史状态，但它随上下文长度、层数和并发请求数增长，会占据大量显存。

14.4 服务系统的组成

功能 作用
模型加载 把参数放入一个或多个计算设备
输入处理 应用对话格式并执行 Tokenization
请求调度 决定哪些请求在何时一起运行
Batch 管理 把多请求组合为高效矩阵计算
Cache 管理 分配、保存和释放 KV Cache
解码与采样 根据 logits 选择 Token
输出流 把生成结果逐步返回调用方
资源控制与监控 管理并发、长度、延迟、错误和成本

具体软件可以替换，但这些功能无法靠“加载一个权重文件”自动消失。

15. 工具调用与 Agent 在哪一层

工具说明会被序列化为 Token；经过后训练的模型生成符合约定的工具名称和参数；外部 Agent Runtime 解析它，真正执行工具，再把结果放回上下文。

因此

工具调用=模型的结构化生成+外部执行器+交互协议. \text{工具调用} = \text{模型的结构化生成} + \text{外部执行器} + \text{交互协议}.

模型本身通常不直接访问数据库、浏览器或操作系统。你已有的 Agent 经验主要位于技术栈最上层：它依赖 LLM，却不等于 LLM 内部结构。

17. 四种完成边界

17.1 数学闭合

你能够明确写出

𝒱t→ℝt×d→ℝt×V→ΔV−1, \mathcal V^t \longrightarrow \mathbb R^{t\times d} \longrightarrow \mathbb R^{t\times V} \longrightarrow \Delta^{V-1},

解释每个空间、每个矩阵形状、条件概率、交叉熵和梯度来源。

19. 参考答案

  1. 输出属于概率单纯形 ΔV−1\Delta^{V-1}，即词表上的概率分布集合。
  2. 三维 Tensor 通常指有三条轴的数组；矩阵秩是线性映射像空间维数；一般张量秩是简单张量分解的最小项数。
  3. 仿射映射的复合仍是仿射映射；非线性激活才使函数族突破单个仿射变换。
  4. 序列似然是各条件概率的乘积；取对数变为和；最大化对数似然等价于最小化负对数似然，而 one-hot 交叉熵正是负对数概率。
  5. 写成 ℒ=−zy+log∑iezi\mathcal L=-z_y+\log\sum_i e^{z_i}，求导得 ∂ℒ/∂zj=qj−𝟏{j=y}\partial\mathcal L/\partial z_j=q_j-\mathbf1_{\{j=y\}}。
  6. Query 决定当前位置寻找哪些特征，Key 决定历史位置如何被匹配，Value 决定匹配后实际传递的信息。
  7. 若任意一层允许读取未来，未来信息就可经隐藏状态传回当前位置，破坏 p(xt+1∣x≤t)p(x_{t+1}\mid x_{\le t}) 的条件结构。
  8. 训练时真实历史 Token 已给出，可用因果 Mask 并行；生成时下一 Token 尚不存在，必须先产生它才能构造下一步上下文。
  9. 它缓存各层历史 Token 的 Key 和 Value，避免重复计算历史状态；但新 Query 仍需与历史 Key 交互，Cache 显存也随上下文增长。
  10. 模型只生成结构化 Token；外部 Runtime 解析、验证并实际调用工具，再把结果写回上下文。

20. 结论压缩

全文可以压缩成四条连接：

字符串→TokenizerToken ID→Embedding向量序列 \boxed{ \text{字符串} \xrightarrow{\text{Tokenizer}} \text{Token ID} \xrightarrow{\text{Embedding}} \text{向量序列} }

向量序列→Attention + MLP上下文化表示→LM Head + Softmax下一 Token 概率 \boxed{ \text{向量序列} \xrightarrow{\text{Attention + MLP}} \text{上下文化表示} \xrightarrow{\text{LM Head + Softmax}} \text{下一 Token 概率} }

真实 Token+预测概率→交叉熵损失→反向传播与优化Base GPT 权重 \boxed{ \text{真实 Token}+\text{预测概率} \xrightarrow{\text{交叉熵}} \text{损失} \xrightarrow{\text{反向传播与优化}} \text{Base GPT 权重} }

Base GPT→指令与偏好数据助手模型→推理服务API→外部执行循环Agent \boxed{ \text{Base GPT} \xrightarrow{\text{指令与偏好数据}} \text{助手模型} \xrightarrow{\text{推理服务}} \text{API} \xrightarrow{\text{外部执行循环}} \text{Agent} }

用一句完整的话概括：

GPT 是定义在有限 Token 序列上的参数化条件概率模型；Tokenizer 决定离散输入，Embedding 把符号变成向量，因果 Transformer 让每个位置从历史 Token 聚合信息，LM Head 与 Softmax 产生下一 Token 的概率，交叉熵把最大似然目标变成可微损失，反向传播和优化从语料中得到参数；后训练再把续写模型变为助手，推理系统最后把参数变成可调用的 API。
